# CU-14 - Seleccionar Responsable Compatible

- **Tipo de caso de uso:** Include (parte de CU-01: Registrar Práctica Profesional)
- **Actor principal:** Alumno
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Grupo
- **Fecha de creación:** 09/04/2026
- **Versión:** V1.0

## Descripción
Permitir al sistema proponer un responsable compatible con el área profesional seleccionada por el alumno.

## Precondiciones
1. Deben existir responsables registrados (CU-07).
2. La empresa debe estar registrada (CU-05).
3. Debe existir un convenio registrado (CU-06).

## Punto de extensión
N/A

## Curso normal
1. El sistema recibe la práctica profesional seleccionada por el alumno.
2. El sistema carga los responsables registrados que la empresa ofrece para monitorear las actividades a desarrollar por el alumno.
3. El sistema filtra los responsables con conocimientos afines al área profesional.
4. El sistema propone responsables compatibles.
5. Fin del caso de uso.

## Cursos alternativos

### A1. No existen responsables registrados (a partir del paso 2)
- A1a. El sistema informa que no existen responsables registrados para esa empresa.
- A1b. El escenario vuelve al paso 1 del curso normal.

### A2. No existen responsables con conocimientos afines al área profesional (a partir del paso 3)
- A2a. El sistema informa que no existen responsables con conocimientos afines al área profesional.
- A2b. El escenario vuelve al paso 1 del curso normal.

## Postcondiciones
1. El sistema informa los responsables compatibles.
