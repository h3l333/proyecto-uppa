# CU-07 - Asignar Responsable a Empresa

- **Tipo de caso de uso:** Base
- **Actor principal:** Administrador del Sistema
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Martín Defez
- **Fecha de creación:** 07/04/2026
- **Versión:** V1.1

## Descripción
Permitir al administrador asociar uno o más responsables de empresa a una empresa determinada, para que luego puedan ser seleccionados en una práctica profesional.

## Precondiciones
1. El administrador debe estar autenticado en el sistema.
2. Debe existir una empresa registrada.
3. El administrador debe encontrarse habilitado.
4. Deben existir los datos del responsable a asociar, o poder ser cargados en el momento.

## Punto de extensión
N/A

## Curso normal
1. El administrador accede a la opción de asignación.
2. El sistema solicita la empresa destino.
3. El administrador selecciona la empresa.
4. El sistema muestra los responsables ya asociados y la opción de incorporar uno nuevo o vincular uno existente.
5. El administrador ingresa o selecciona el responsable.
6. El administrador registra los datos relevantes del responsable y sus áreas de conocimiento afines.
7. El sistema valida los datos obligatorios.
8. El administrador confirma la operación.
9. El sistema asocia el responsable a la empresa.
10. El sistema informa que la asignación fue realizada correctamente.

## Cursos alternativos

### A1. Empresa inexistente
- A1a. El sistema informa que la empresa seleccionada no es válida.
- A1b. El administrador debe seleccionar otra empresa.

### A2. Responsable ya asociado a la empresa
- A2a. El sistema informa que el responsable ya se encuentra vinculado a esa empresa.
- A2b. La operación se cancela o se mantiene sin cambios.

### A3. Datos incompletos del responsable
- A3a. El sistema informa qué datos faltan completar.
- A3b. El administrador corrige la carga y continúa.

## Postcondiciones
1. El responsable queda asociado a la empresa.
2. El responsable puede ser considerado luego en el registro de prácticas, siempre que resulte compatible con el área profesional correspondiente.

## Interfaz de diseño (GUI)
Formulario "Asignar Responsable a Empresa" con los campos:
- Empresa (desplegable de selección)
- Responsables actuales (listado, por ejemplo "Juan Pérez")
- Tipo de acción (desplegable)
- Botón "Confirmar Asignación"
