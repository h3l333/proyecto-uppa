# CU-01 - Registrar Práctica Profesional

- **Tipo de caso de uso:** Base
- **Actor principal:** Alumno
- **Actor secundario:** Sistema de Correo
- **Prioridad:** Alta
- **Autor:** Martín Defez
- **Fecha de creación:** 31/03/2026
- **Versión:** V1.2

## Descripción
Permitir que un alumno registre su práctica profesional en una empresa con convenio vigente, asignando tutor académico y responsable de empresa compatibles con el área profesional.

## Precondiciones
1. El alumno debe estar autenticado en el sistema.
2. El alumno debe estar registrado en el sistema.
3. La empresa debe existir en el sistema.
4. Debe existir al menos un convenio registrado para la empresa.
5. Deben existir tutores y responsables compatibles con el área profesional elegida.

## Punto de extensión
Si la empresa es del sector público, el sistema verifica que exista cupo disponible.

## Curso normal
1. El alumno accede a la opción Registrar Práctica Profesional.
2. El sistema muestra la interfaz de registro de prácticas profesionales junto a los campos asociados.
3. El sistema carga las empresas registradas.
4. El alumno selecciona la empresa.
5. El sistema verifica que existan convenios vigentes registrados.
6. El sistema carga los convenios vigentes.
7. El sistema muestra los convenios asociados.
8. El alumno selecciona un convenio.
9. El alumno ingresa la fecha de inicio y la fecha de fin de la práctica.
10. El sistema verifica que el alumno no tenga otra práctica en el mismo ciclo lectivo.
11. Si la empresa es del sector público, el sistema verifica que exista cupo disponible.
12. El sistema verifica la existencia de al menos un tutor compatible.
13. El sistema selecciona y asigna un tutor académico compatible.
14. El sistema carga los responsables de la empresa compatibles.
15. El sistema muestra los responsables de la empresa compatibles.
16. El alumno selecciona un responsable.
17. El alumno confirma el registro.
18. El sistema registra la práctica con estado pendiente.
19. El sistema envía notificación por correo al alumno, al tutor y al responsable.
20. El sistema informa que la operación finalizó correctamente.

## Cursos alternativos

### A1. Convenio no vigente
- A1a. El sistema informa que el convenio no se encuentra vigente.
- A1b. El registro no puede continuar.

### A2. El alumno ya posee una práctica en el mismo ciclo lectivo
- A2a. El sistema informa que el alumno ya tiene una práctica registrada en ese ciclo.
- A2b. El registro no puede continuar.

### A3. Empresa pública sin cupo disponible
- A3a. El sistema informa que no hay cupo disponible.
- A3b. El registro no puede continuar.

### A4. No existen tutores compatibles
- A4a. El sistema informa que no hay tutor disponible para el área seleccionada.
- A4b. El registro no puede continuar.

### A5. No existen responsables compatibles
- A5a. El sistema informa que no hay responsables compatibles para el área seleccionada.
- A5b. El registro no puede continuar.

### A6. Fechas inválidas
- A6a. Si la fecha de fin es menor o igual a la fecha de inicio, el sistema informa el error.
- A6b. El alumno debe corregir los datos.

## Postcondiciones
1. La práctica queda registrada.
2. El estado inicial de la práctica queda en pendiente.
3. Se notifica al alumno, al tutor y al responsable.
4. La práctica queda asociada a la empresa, el convenio, el tutor y el responsable.
