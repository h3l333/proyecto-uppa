# CU-13 - Proponer Tutor Académico Compatible

- **Tipo de caso de uso:** Include (parte de CU-01: Registrar Práctica Profesional)
- **Actor principal:** Sistema de Gestión de Prácticas UPPA
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Grupo
- **Fecha de creación:** 09/04/2026
- **Versión:** V1.0

## Descripción
Permitir proponer un tutor académico compatible para el alumno.

## Precondiciones
1. La empresa debe estar registrada (CU-05).
2. Debe existir un convenio registrado (CU-06).

## Punto de extensión
N/A

## Curso normal
1. El sistema recibe la práctica profesional seleccionada por el alumno.
2. El sistema carga los docentes de la universidad registrados en el sistema.
3. El sistema filtra los docentes con conocimientos en el área seleccionada por el alumno.
4. El sistema propone un tutor académico compatible.
5. Fin del caso de uso.

## Cursos alternativos

### A1. No existen docentes registrados (a partir del paso 2)
- A1a. El sistema informa que no existen docentes registrados.
- A1b. El escenario vuelve al paso 1 del curso normal.

### A2. No existen tutores compatibles con el área profesional (a partir del paso 4)
- A2a. El sistema informa que no existen tutores compatibles relacionados con el área profesional.
- A2b. El escenario vuelve al paso 3 del curso normal.

## Postcondiciones
1. El sistema informa el tutor académico propuesto.
