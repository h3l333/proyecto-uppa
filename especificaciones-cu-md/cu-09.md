# CU-09 - Consultar Convenios Próximos a Vencer

- **Tipo de caso de uso:** Base
- **Actor principal:** Administrador del Sistema
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Martín Defez
- **Fecha de creación:** 07/04/2026
- **Versión:** V1.1

## Descripción
Permitir al administrador consultar los convenios cuya fecha de vencimiento se encuentra próxima, a fin de facilitar su control y eventual renovación.

## Precondiciones
1. El administrador debe estar autenticado en el sistema.
2. Deben existir convenios registrados en el sistema.
3. El administrador debe encontrarse habilitado.

## Punto de extensión
N/A

## Curso normal
1. El administrador accede a la opción de consulta.
2. El sistema muestra criterios de búsqueda y filtros.
3. El administrador ingresa uno o más criterios.
4. El sistema valida los criterios ingresados.
5. El sistema recupera los convenios cuyo vencimiento se encuentra dentro del rango indicado.
6. El sistema muestra un listado con los convenios encontrados, indicando empresa, fecha de inicio, fecha de vencimiento y estado de vigencia.
7. El administrador finaliza la consulta.

## Cursos alternativos

### A1. No se encuentran convenios próximos a vencer
- A1a. El sistema informa que no existen convenios dentro del criterio indicado.
- A1b. El administrador puede modificar los parámetros o finalizar la operación.

### A2. Parámetros inválidos
- A2a. El sistema informa el error de validación.
- A2b. El administrador corrige los datos.

## Postcondiciones
1. El sistema muestra el listado de convenios próximos a vencer.
2. No se modifica información.
