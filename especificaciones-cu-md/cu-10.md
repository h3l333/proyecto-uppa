# CU-10 - Verificar Vigencia del Convenio

- **Tipo de caso de uso:** Include (parte de CU-01: Registrar Práctica Profesional)
- **Actor principal:** Sistema de Gestión de Prácticas UPPA
- **Actor secundario:** Alumno
- **Prioridad:** Alta
- **Autor:** Helena Cusworth
- **Fecha de creación:** 07/04/2026
- **Versión:** V1

## Descripción
Validar que el convenio seleccionado para una práctica profesional se encuentre vigente y cuente con cupo disponible (en caso de empresas públicas) antes de permitir el registro.

## Precondiciones
1. El alumno ha seleccionado una empresa y un convenio específico para su práctica.
2. Los datos del convenio (fecha de inicio, duración) están cargados en el sistema.

## Punto de extensión
N/A

## Curso normal
1. El sistema recibe la solicitud de validación del convenio seleccionado.
2. El sistema calcula la fecha de vencimiento sumando la duración del convenio a su fecha de inicio.
3. El sistema compara la fecha actual con la fecha de vencimiento calculada.
4. El sistema verifica el tipo de empresa; si es del sector público, consulta la cantidad de alumnos con prácticas en curso vinculadas a ese convenio.
5. El sistema confirma que la fecha actual es anterior al vencimiento y, si aplica, que existen cupos disponibles.
6. El sistema habilita la continuación del proceso de registro de la práctica profesional.

## Cursos alternativos

### A1. Convenio vencido (a partir del paso 3)
- A1a. El sistema detecta que la fecha actual es posterior a la fecha de fin del convenio.
- A1b. El sistema bloquea el registro y muestra un mensaje de error.

### A2. Cupo excedido - solo sector público (a partir del paso 4)
- A2a. El sistema detecta que el número de alumnos activos es igual al cupo definido.
- A2b. El sistema bloquea el registro y muestra un mensaje de error.

## Postcondiciones
1. El resultado de la validación queda disponible para continuar o detener el registro de la práctica.
2. El sistema no modifica ninguno de los datos almacenados como resultado de la operación.
