# CU-15 - Notificar Alta de Práctica

- **Tipo de caso de uso:** Base (automático) / Include (parte de CU-01: Registrar Práctica Profesional)
- **Actor principal:** Sistema de Correo Electrónico
- **Actor secundario:** Alumno, Tutor, Responsable
- **Prioridad:** Media
- **Autor:** Helena Cusworth
- **Fecha de creación:** 07/04/2026
- **Versión:** V1

## Descripción
Enviar automáticamente correos electrónicos de notificación al alumno, al tutor académico y al responsable de la empresa una vez que la práctica profesional ha sido registrada exitosamente en el sistema.

## Precondiciones
1. La práctica profesional está validada y guardada en el sistema.
2. El sistema dispone de las direcciones de correo electrónico de los tres actores involucrados.
3. El servidor del servicio de correo electrónico se encuentra vigente.

## Punto de extensión
N/A

## Curso normal
1. El sistema detecta la confirmación del registro exitoso de una nueva práctica profesional.
2. El sistema recupera los datos de contacto y los nombres del alumno, el tutor y el responsable asignado.
3. El sistema redacta los cuerpos de los correos utilizando plantillas predefinidas.
4. El sistema envía los correos electrónicos de forma simultánea a los tres destinatarios.
5. El sistema registra en el log de la práctica la fecha y hora exacta del envío de las notificaciones.

## Cursos alternativos

### A1. Datos de contacto incompletos (a partir del paso 2)
- A1a. El sistema cancela el envío para el destinatario con datos incompletos.
- A1b. Se notifica al administrador del sistema sobre la falta de datos.

### A2. Fallo en el servidor del sistema de correo (a partir del paso 4)
- A2a. El sistema detecta que el correo no pudo ser enviado.
- A2b. El sistema notifica al administrador del sistema sobre el fallo.

## Postcondiciones
- En caso de éxito: los tres actores secundarios quedan notificados correctamente.
- En caso de fallo: el administrador del sistema queda notificado sobre el fallo ocurrido.

## Interfaz de diseño (GUI)
Correo "Confirmación de Alta de Práctica Profesional" (Gestión de Prácticas UPPA), con los datos:
- Alumno (con ID)
- Empresa / Institución
- Tutor académico (UPPA)
- Responsable de empresa
- Período (fecha de inicio a fecha de fin)
- Enlace "Acceder al Sistema de Gestión"
