# CU-11 - Verificar Práctica Única por Ciclo Lectivo

- **Tipo de caso de uso:** Include (parte de CU-01: Registrar Práctica Profesional)
- **Actor principal:** Sistema de Gestión de Prácticas UPPA
- **Actor secundario:** Alumno
- **Prioridad:** Alta
- **Autor:** Helena Cusworth
- **Fecha de creación:** 07/04/2026
- **Versión:** V1

## Descripción
Asegurar que el alumno no posea más de una práctica profesional registrada dentro del mismo año académico o ciclo lectivo vigente.

## Precondiciones
1. El alumno está autenticado y ha iniciado el proceso de inscripción de una nueva práctica.
2. El sistema tiene definido el rango de fechas del ciclo lectivo actual.

## Punto de extensión
N/A

## Curso normal
1. El sistema recibe la solicitud de inscripción del alumno.
2. El sistema identifica el ciclo lectivo actual en base a la fecha del servidor.
3. El sistema consulta en la base de datos si existe alguna práctica profesional asociada a la matrícula del alumno cuyas fechas de inicio coincidan con el ciclo lectivo vigente.
4. El sistema verifica que no existan registros previos para el alumno.
5. En caso de que no los haya, el sistema valida la solicitud y permite al actor continuar.

## Cursos alternativos

### A1. Práctica existente detectada (a partir del paso 3)
- A1a. El sistema bloquea el proceso de inscripción.
- A1b. El sistema muestra un mensaje de error.
- A1c. El sistema retorna a la página inicial.

## Postcondiciones
1. En caso de éxito, se autoriza al alumno a proceder con el registro.
2. En caso de fallo, se previene la duplicidad de prácticas.
