# CU-08 - Asignar Tutor a Área Profesional

- **Tipo de caso de uso:** Base
- **Actor principal:** Administrador del Sistema
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Martín Defez
- **Fecha de creación:** 07/04/2026
- **Versión:** V1.1

## Descripción
Permitir al administrador asociar tutores académicos a áreas profesionales, a fin de posibilitar luego la asignación automática o sugerida de un tutor compatible durante el registro de una práctica.

## Precondiciones
1. El administrador debe estar autenticado en el sistema.
2. Debe existir el tutor académico en el sistema institucional.
3. Debe existir el área profesional definida por la universidad.
4. El administrador debe encontrarse habilitado.

## Punto de extensión
N/A

## Curso normal
1. El administrador accede a la opción de asignación.
2. El sistema muestra el listado de tutores y áreas profesionales disponibles.
3. El administrador selecciona un tutor.
4. El administrador selecciona una o más áreas profesionales.
5. El sistema valida que la información esté completa.
6. El administrador confirma la operación.
7. El sistema registra la asociación entre el tutor y el área profesional.
8. El sistema informa que la asignación fue realizada correctamente.

## Cursos alternativos

### A1. Tutor inexistente o inválido
- A1a. El sistema informa que el tutor seleccionado no es válido.
- A1b. El administrador corrige la selección.

### A2. Área profesional no seleccionada
- A2a. El sistema informa que debe seleccionarse al menos un área profesional.
- A2b. El administrador completa la información.

### A3. Asignación ya existente
- A3a. El sistema informa que el tutor ya se encuentra asociado a esa área.
- A3b. No se duplica la relación.

## Postcondiciones
1. El tutor queda asociado a una o más áreas profesionales.
