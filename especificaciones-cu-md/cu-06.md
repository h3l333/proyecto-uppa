# CU-06 - Registrar Convenio

- **Tipo de caso de uso:** Base
- **Actor principal:** Administrador del Sistema
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Martín Defez
- **Fecha de creación:** 07/04/2026
- **Versión:** V1.1

## Descripción
Permitir al administrador registrar un convenio asociado a una empresa, indicando su vigencia para que pueda ser utilizado en el registro de prácticas profesionales.

## Precondiciones
1. El administrador debe estar autenticado en el sistema.
2. Debe existir una empresa previamente registrada.
3. El administrador debe encontrarse habilitado para operar.

## Punto de extensión
N/A

## Curso normal
1. El administrador accede a la opción de registrar un convenio.
2. El sistema muestra el formulario de alta de convenio.
3. El administrador selecciona la empresa a la que se asociará el convenio.
4. El administrador ingresa la fecha de inicio y la duración o fecha de finalización del convenio.
5. El sistema valida que los datos obligatorios estén completos.
6. El sistema valida que las fechas sean consistentes.
7. El administrador confirma la operación.
8. El sistema registra el convenio y lo asocia a la empresa seleccionada.
9. El sistema informa que el convenio fue registrado correctamente.

## Cursos alternativos

### A1. No existe empresa seleccionada
- A1a. El sistema informa que debe seleccionarse una empresa válida.
- A1b. El administrador corrige el dato.

### A2. Fechas inválidas
- A2a. El sistema informa que la fecha de finalización debe ser posterior a la fecha de inicio.
- A2b. El administrador corrige la información.

### A3. Datos obligatorios incompletos
- A3a. El sistema informa qué campos faltan completar.
- A3b. El administrador completa los datos y continúa.

## Postcondiciones
1. El convenio queda registrado y asociado a una empresa.
2. El convenio puede ser considerado luego en el proceso de registro de prácticas, sujeto a su vigencia.
