# CU-16 - Notificar sobre Vencimiento

- **Tipo de caso de uso:** Base (automático)
- **Actor principal:** Sistema de Correo Electrónico
- **Actor secundario:** Responsable de la Empresa, Administrador del Sistema
- **Prioridad:** Alta
- **Autor:** Helena Cusworth
- **Fecha de creación:** 07/04/2026
- **Versión:** V1

## Descripción
Detectar convenios con empresas próximos a expirar y enviar notificaciones preventivas al administrador y al responsable de la empresa.

## Precondiciones
1. Existen convenios registrados con fecha de fin válida.
2. El servidor del sistema de correo electrónico está operativo.
3. El servicio de correo electrónico se encuentra vigente.

## Punto de extensión
N/A

## Curso normal
1. El sistema inicia el proceso de verificación.
2. El sistema recupera los convenios con vencimiento próximo.
3. El sistema recupera los correos de los destinatarios indicados.
4. El sistema redacta el cuerpo de los correos con la plantilla especificada.
5. El sistema envía al responsable y al administrador las notificaciones correspondientes.
6. El sistema registra en el log el envío de las notificaciones.

## Cursos alternativos

### A1. No se detectan convenios por vencer (a partir del paso 2)
- A1a. El sistema detecta que no hay convenios por vencer.
- A1b. Fin del caso de uso.

### A2. Fallo en el sistema de correo electrónico (a partir del paso 5)
- A2a. El sistema detecta que el servicio de correo electrónico se encuentra caído.
- A2b. El administrador del sistema es notificado sobre el fallo.

## Postcondiciones
- En caso de éxito: la notificación de los dos actores secundarios es exitosa.
- En caso de fallo: el administrador del sistema queda notificado sobre el fallo ocurrido.

## Interfaz de diseño (GUI)
Correo "Aviso de Vencimiento" (Gestión de Prácticas UPPA), con los datos:
- Empresa / Institución
- CUIT
- Fecha de vencimiento (con cuenta regresiva)
- Responsable
- Botón "Gestionar Renovación de Convenio"
