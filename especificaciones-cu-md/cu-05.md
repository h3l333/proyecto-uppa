# CU-05 - Registrar Empresa

- **Tipo de caso de uso:** Base
- **Actor principal:** Administrador del Sistema
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Martín Defez
- **Fecha de creación:** 07/04/2026
- **Versión:** V1.1

## Descripción
Permitir al administrador registrar una empresa con la que la universidad podrá gestionar prácticas profesionales.

## Precondiciones
1. El administrador debe estar autenticado en el sistema.
2. La empresa no debe existir previamente registrada con el mismo CUIT.

## Punto de extensión
N/A

## Curso normal
1. El administrador accede a la opción de registrar empresa.
2. El sistema muestra el formulario de alta.
3. El administrador ingresa los datos de la empresa: nombre, CUIT, rubro, ubicación y sector.
4. El sistema valida que los datos obligatorios estén completos.
5. El sistema valida que no exista otra empresa registrada con el mismo CUIT.
6. El administrador confirma la operación.
7. El sistema registra la empresa.
8. El sistema informa que el alta fue realizada correctamente.

## Cursos alternativos

### A1. Número de CUIT ya registrado
- A1a. El sistema informa que ya existe una empresa con ese CUIT.
- A1b. El administrador puede corregir el dato o cancelar la operación.

### A2. Datos obligatorios incompletos
- A2a. El sistema informa qué datos están incompletos.
- A2b. El administrador completa la información y continúa.

## Postcondiciones
1. La empresa queda registrada en el sistema.
2. La empresa puede luego asociarse a uno o más convenios.

## Interfaz de diseño (GUI)
Formulario "Registro de Empresa" con los campos:
- Nombre de la Empresa
- CUIT (formato XX-XXXXXXXX-X)
- Rubro
- Sector (desplegable)
- Ubicación
- Validación: el sistema verifica que todos los campos estén completos y que el CUIT no esté previamente registrado.
- Botón "Confirmar Registro"
