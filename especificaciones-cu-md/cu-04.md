# CU-04 - Consultar Seguimiento de Práctica

- **Tipo de caso de uso:** Base
- **Actor principal:** Tutor / Responsable de Empresa
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Martín Defez
- **Fecha de creación:** 07/04/2026
- **Versión:** V1.1

## Descripción
Permitir al tutor o al responsable de la empresa consultar el seguimiento de las prácticas profesionales registradas, visualizando su estado, empresa asociada, período, tutor, responsable e informes de avance cargados.

## Precondiciones
1. El actor debe estar autenticado en el sistema.
2. La práctica debe existir.
3. La práctica debe estar asociada al actor que realiza la consulta.
4. La práctica debe encontrarse en seguimiento operativo.

## Punto de extensión
N/A

## Curso normal
1. El actor accede a la opción de Consulta de Seguimiento.
2. El sistema muestra criterios de búsqueda y filtros.
3. El actor ingresa uno o más criterios de búsqueda, por ejemplo: alumno, empresa, estado o período.
4. El sistema valida los criterios ingresados.
5. El sistema recupera las prácticas que cumplen con las condiciones de búsqueda.
6. El sistema muestra un listado con las prácticas encontradas.
7. El actor selecciona una práctica del listado.
8. El sistema muestra el detalle del seguimiento de la práctica seleccionada, incluyendo estado, fechas, tutor, responsable e informes de avance asociados.
9. El actor finaliza la consulta.

## Cursos alternativos

### A1. No existen prácticas que cumplan el criterio
- A1a. El sistema informa que no se encontraron resultados.
- A1b. El actor puede modificar los filtros o finalizar la operación.

### A2. Criterios de búsqueda inválidos o incompletos
- A2a. El sistema informa el error.
- A2b. El actor corrige los datos y reintenta la búsqueda.

## Postcondiciones
1. El sistema muestra el detalle del seguimiento de una o más prácticas.
2. No se modifica información; el caso es únicamente de consulta.
