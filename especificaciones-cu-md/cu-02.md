# CU-02 - Generar Informe de Avance

- **Tipo de caso de uso:** Base
- **Actor principal:** Tutor / Responsable de Empresa
- **Actor secundario:** N/A
- **Prioridad:** Alta
- **Autor:** Martín Defez
- **Fecha de creación:** 31/03/2026
- **Versión:** V1.1

## Descripción
Permitir al tutor o al responsable de la empresa registrar un informe de avance de la práctica profesional de un alumno asignado.

## Precondiciones
1. La práctica debe existir.
2. La práctica debe estar asociada al actor que genera el informe.
3. La práctica debe encontrarse en seguimiento operativo.

## Punto de extensión
N/A

## Curso normal
1. El actor accede a la opción Generar Informe de Avance.
2. El sistema muestra el listado de prácticas bajo su seguimiento.
3. El actor selecciona una práctica.
4. El sistema muestra el formulario del informe.
5. El actor ingresa la fecha del informe.
6. El actor ingresa la descripción de las tareas realizadas.
7. El actor ingresa la evaluación parcial.
8. El actor confirma la operación.
9. El sistema valida los datos obligatorios.
10. El sistema registra el informe de avance.
11. El sistema informa que el registro fue exitoso.

## Cursos alternativos

### A1. Estado de práctica incorrecto
- A1a. El sistema informa que la práctica no se encuentra en curso.
- A1b. El actor debe seleccionar otra práctica o cancelar el informe.

### A2. Fecha fuera del período de práctica
- A2a. El sistema informa que la fecha del informe no es válida respecto del período de práctica.
- A2b. El actor debe corregir la fecha.

## Postcondiciones
1. El informe queda registrado en el sistema.
2. El informe queda vinculado a la práctica profesional.
3. El seguimiento de la práctica queda actualizado.
